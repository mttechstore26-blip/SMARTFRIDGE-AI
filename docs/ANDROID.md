# Android

Aprire SmartFridge AI con Chrome Android in un contesto HTTPS o localhost. Concedere la fotocamera solo quando si usa ENTRATA/USCITA e il microfono solo quando si preme Ehi Frigo. Dal menu Chrome scegliere “Installa app” o “Aggiungi a schermata Home”.

La schermata nera dopo il tempo configurato è standby applicativo: il display fisico resta acceso. Per spegnimento, risveglio e gestione energetica servirà un wrapper Capacitor/app nativa con API Android e permessi espliciti. Testare fotocamera posteriore, orientamento e leggibilità su tablet 7–10 pollici prima di fissare il dispositivo al frigorifero.
